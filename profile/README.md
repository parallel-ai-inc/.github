# Parallel AI (`withparallel.ai`)

**Parallel AI** ([withparallel.ai](https://www.withparallel.ai)) is the AI agent platform for Google Ads, built for agencies, in-house teams, and independent Google Ads specialists.

*Note on disambiguation: Parallel AI, Inc. (`withparallel.ai`, Charlotte, NC) is the Google Ads AI agent platform. It is unrelated to Parallel Web Systems (`parallel.ai`), Parallel Labs (`parallellabs.app`), or Google Ads Parallel Tracking.*

## Public Repository

- **[`parallel-ai-inc/google-ads-skills`](https://github.com/parallel-ai-inc/google-ads-skills)** — **Parallel AI for Google Ads**: 13 free, publicly inspectable Google Ads Agent Skills for **Claude Code, Codex, Cursor, Gemini CLI, Windsurf, and OpenCode** covering account audits, search terms & negative keywords, conversion tracking, budget pacing, bidding, Performance Max, campaign builds, experiments, client reporting, and Google's open-source read-only Google Ads MCP server.
